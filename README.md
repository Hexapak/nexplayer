# NexPlayer Pro - With Screen Lock & PiP Support

### Features Added:
1. **MX Player Style Screen Lock:** Tap the lock icon on the top-left to lock the screen so accidental touches won't disrupt your viewing. Tap it again to unlock.
2. **Auto Picture-in-Picture (PiP):** Minimize or leave the app while watching a video to automatically enter floating PiP mode.
3. **ExoPlayer Media3 Engine:** Smooth streaming and local file playback with hardware acceleration.

### How to Build:
Upload this project folder to GitHub Codespaces or open it in Android Studio to build your APK!
